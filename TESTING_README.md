## 🚀 Быстрый старт

```bash
# 1. Установите зависимости
npm install
npx playwright install chromium

# 2. Убедитесь, что серверы запущены
./start.sh

# 3. Запустите все тесты
npm test

# 4. Посмотрите отчет
npm run report
```

## 📦 Установка

### Предварительные требования

- **Node.js** версии 16 или выше
- **Python 3.9+** (для Flask API)
- Все Python зависимости установлены (`pip install -r requirements.txt`)

### Установка Playwright

```bash
# Установить Playwright и зависимости
npm install

# Установить браузеры (только Chromium для экономии места)
npx playwright install chromium

# Или установить все браузеры (опционально)
npx playwright install
```

## 🏃 Запуск тестов

### Основные команды

```bash
# Запустить ВСЕ тесты
npm test

# Запустить тесты с графическим интерфейсом
npm run test:ui

# Запустить тесты в режиме отладки
npm run test:debug

# Запустить тесты с отображением браузера
npm run test:headed
```

### Запуск конкретных групп тестов

```bash
# Только CREATE тесты
npm run test:create

# Только READ тесты
npm run test:read

# Только UPDATE тесты
npm run test:update

# Только DELETE тесты
npm run test:delete

# Только SCORING тесты
npm run test:scoring
```

### Запуск конкретного теста

```bash
# Запустить конкретный файл
npx playwright test tests/e2e/01-create-operations.spec.js

# Запустить конкретный тест по названию
npx playwright test --grep "TC_001"
```

## 📊 Просмотр отчетов

После запуска тестов, отчеты автоматически генерируются в папке `test-results/`.

### HTML отчет

```bash
# Открыть HTML отчет в браузере
npm run report
```

HTML отчет содержит:
- ✅ Список пройденных тестов
- ❌ Список упавших тестов
- ⏱️ Время выполнения каждого теста
- 📸 Скриншоты при ошибках
- 🎥 Видео записи упавших тестов
- 📋 Детальные логи

### JSON отчет

JSON отчет находится в `test-results/results.json` и может быть использован для интеграции с CI/CD.

## 🧹 Очистка тестовых данных

Все тесты автоматически очищают созданные данные после выполнения благодаря fixture `autoCleanup`.

### Ручная очистка

Если нужно вручную очистить тестовые данные:

```bash
# Запустить скрипт очистки
npm run cleanup
```

Или использовать утилиту напрямую:

```javascript
const { cleanupAllTestData } = require('./tests/utils/cleanup');

// В тесте:
await cleanupAllTestData(request);
```

### Что удаляется при очистке?

- Все викторины с префиксом `[TEST]`
- Все вопросы с префиксом `[TEST]`
- Все связанные изображения
- Все попытки прохождения тестовых викторин
- Все тестовые PDF записи

## 🔧 Решение проблем

### Тесты не запускаются

**Проблема:** `Error: Cannot find module '@playwright/test'`

**Решение:**
```bash
npm install
npx playwright install chromium
```

---

### Серверы не запускаются автоматически

**Проблема:** Тесты ждут подключения к серверам, но они не стартуют

**Решение:** Запустите серверы вручную перед тестами:
```bash
./start.sh
```

Затем в `playwright.config.js` установите `reuseExistingServer: true`.

---

### Ошибки подключения к API

**Проблема:** `ECONNREFUSED localhost:5001`

**Решение:**
1. Проверьте, что API сервер запущен:
   ```bash
   curl http://localhost:5001/api/health
   ```

2. Если не отвечает, перезапустите:
   ```bash
   ./stop.sh && ./start.sh
   ```

---

### Тесты падают из-за конфликтов в БД

**Проблема:** Ошибки вида "UNIQUE constraint failed"

**Решение:**
1. Очистите тестовые данные:
   ```bash
   npm run cleanup
   ```

2. Убедитесь, что `fullyParallel: false` в `playwright.config.js`

---

### Браузер не установлен

**Проблема:** `Executable doesn't exist at ...`

**Решение:**
```bash
npx playwright install chromium
```

## 🎯 Рекомендации по написанию новых тестов

### 1. Используйте готовые хелперы

```javascript
const { test, expect } = require('../fixtures/base-fixtures');

test('Мой тест', async ({ api, request }) => {
  // api содержит все хелперы из api-helpers.js
  const quiz = await api.createQuiz(request, {...});
});
```

### 2. Используйте тестовые данные

```javascript
const { generateRandomQuiz, singleChoiceQuestions } = require('../data/test-data');

// Генерация уникальной викторины
const quiz = generateRandomQuiz();

// Использование готовых данных
const question = singleChoiceQuestions[0];
```

### 3. Группируйте тесты по функциональности

```javascript
test.describe('Моя группа тестов @mytag', () => {
  test('Тест 1', async ({ api, request }) => {
    // ...
  });

  test('Тест 2', async ({ api, request }) => {
    // ...
  });
});
```

### 4. Добавляйте подробные логи

```javascript
console.log('\n📝 Тест TC_XXX: Описание теста');
// ... код теста ...
console.log(`✓ Результат: ${result}`);
```

### 5. Используйте `.skip()` для временного отключения

```javascript
test.skip('Этот тест временно отключен', async () => {
  // ...
});
```

## ✅ Checklist для добавления новых тестов

- [ ] Тест использует префикс `[TEST]` для всех создаваемых данных
- [ ] Тест использует `test` из `base-fixtures` для автоочистки
- [ ] Тест имеет понятное название и описание
- [ ] Тест содержит проверки (`expect`) для всех критичных условий
- [ ] Тест логирует свой прогресс с помощью `console.log`
- [ ] Тест добавлен в соответствующую группу (`@create`, `@read`, и т.д.)

# 🎓 Система олимпиадных вопросов

Полноценная система для сбора, хранения и обучения на основе олимпиадных вопросов из разных университетов.

## 📋 Возможности

✅ **Парсинг PDF** - извлечение вопросов из PDF файлов разных форматов
✅ **База данных** - структурированное хранение в SQLite с резервным копированием
✅ **Поддержка изображений** - извлечение графиков, диаграмм, схем
✅ **Типы вопросов** - выбор, множественный выбор, соответствие, текст, эссе
✅ **Управление файлами** - загрузка, метаданные, дедупликация по hash
✅ **Верификация** - система проверки качества вопросов (✅⚠️❌)
✅ **API** - REST API для работы с вопросами и файлами
✅ **Веб-интерфейс** - удобный интерфейс для просмотра и тестирования
✅ **Фильтрация** - по предмету, университету, году, сложности, статусу
✅ **Тестирование** - режим прохождения тестов с проверкой ответов
✅ **Просмотр PDF** - возможность открыть исходный PDF для любого вопроса
✅ **Backup/Sync** - автоматическое резервное копирование и синхронизация

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Создаём виртуальное окружение
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate

# Устанавливаем зависимости
pip install -r requirements.txt
```

### 2. Скачивание олимпиад (опционально)

```bash
# Скачать все олимпиады
python olympiad_downloader.py --full

# Или обновить (только новые)
python olympiad_downloader.py --update
```

### 3. Импорт PDF в базу данных

```bash
# Импортировать один файл
python import_pdfs.py path/to/file.pdf

# Импортировать всю папку
python import_pdfs.py olympiads/downloads

# Импортировать с фильтром (только PDF по обществознанию)
python import_pdfs.py olympiads/downloads --pattern "**/*общество*.pdf"

# Ограничить количество файлов
python import_pdfs.py olympiads/downloads --limit 10
```

### 4. Запуск системы

**Самый простой способ - один скрипт:**

```bash
./start.sh
```

Этот скрипт:
- ✅ Запустит API сервер на `http://localhost:5001`
- ✅ Запустит веб-сервер на `http://localhost:8000`
- ✅ Автоматически откроет браузер
- ✅ Синхронизирует базу данных

**Для остановки:**

```bash
./stop.sh
```

**Или запустить вручную:**

```bash
# Запуск API
cd api
source ../venv/bin/activate
python app.py

# В другом терминале - запуск веб-сервера
cd web
python -m http.server 8000
```

Затем откройте: `http://localhost:8000`

## 📚 Использование

### Просмотр вопросов

1. Откройте вкладку "Просмотр вопросов"
2. Выберите фильтры (предмет, университет, год и т.д.)
3. Нажмите "Применить фильтры"
4. Для любого вопроса можно открыть исходный PDF, нажав кнопку "📄 PDF"

### Тестирование

1. Откройте вкладку "Тестирование"
2. Выберите предмет и количество вопросов
3. Нажмите "Начать тест"
4. Отвечайте на вопросы
5. Получите результат с процентом правильных ответов

### Статистика

Откройте вкладку "Статистика" для просмотра:
- Общего количества вопросов
- Распределения по предметам
- Распределения по университетам

## 🔌 API Эндпоинты

### GET /api/questions
Получить список вопросов с фильтрацией

**Параметры:**
- `subject` - предмет
- `university` - университет
- `year` - год
- `question_type` - тип вопроса
- `difficulty` - сложность (1-5)
- `limit` - количество (по умолчанию 50)
- `offset` - смещение для пагинации

**Пример:**
```bash
curl "http://localhost:5000/api/questions?subject=Обществознание&limit=10"
```

### GET /api/questions/:id
Получить конкретный вопрос

### GET /api/filters
Получить доступные значения для фильтров

### GET /api/stats
Получить статистику базы данных

### GET /api/pdf/:path
Получить исходный PDF файл

### GET /api/random
Получить случайные вопросы для тестирования

### POST /api/check_answer
Проверить ответ на вопрос

**Body:**
```json
{
  "question_id": 1,
  "answer": "Вариант ответа"
}
```

### Управление файлами и верификация

- `GET /api/pdfs` - список PDF файлов с фильтрацией
- `POST /api/pdfs/upload` - загрузка нового PDF (с дедупликацией по SHA256)
- `GET /api/pdfs/:id` - информация о конкретном PDF
- `PUT /api/pdfs/:id` - обновить метаданные PDF
- `POST /api/pdfs/:id/reparse` - перепарсить PDF (превью)
- `POST /api/pdfs/:id/apply-reparse` - применить перепарсинг
- `GET /api/pdfs/:id/verification-stats` - статистика проверки вопросов
- `PUT /api/pdfs/:id/verification-status` - обновить статус верификации
- `PUT /api/questions/:id/verify` - верифицировать вопрос
- `POST /api/questions/bulk-verify` - массовая верификация

### Резервное копирование

- `POST /api/admin/backup` - создать резервную копию БД
- `POST /api/admin/sync-db` - синхронизировать БД

Подробнее см. DATABASE_BACKUP_README.md

## 🗃️ База данных

### Структура

- **questions** - вопросы
- **options** - варианты ответов
- **matching_pairs** - пары для вопросов на соответствие
- **images** - изображения (графики, диаграммы)
- **tags** - теги и метаданные (предмет, университет, год)
- **test_sessions** - сессии тестирования
- **student_answers** - ответы студентов

### Типы вопросов

- `choice` - одиночный выбор
- `multiple_choice` - множественный выбор
- `matching` - соответствие
- `text` - текстовый ответ
- `essay` - эссе с критериями оценивания (см. ESSAY_AND_IMAGES_README.md)

## 🛠️ Расширение функциональности

### Добавление нового источника олимпиад

Отредактируйте `olympiad_downloader.py`, добавив новый источник в `OLYMPIAD_SOURCES`:

```python
"Новый_Универ": {
    "urls": ["https://example.com/olympiads"],
    "type": "selenium"
}
```

### Улучшение парсера PDF

Отредактируйте `parsers/pdf_parser.py`, добавив новые паттерны в:
- `QUESTION_PATTERNS` - для поиска вопросов
- `SCORE_PATTERNS` - для извлечения баллов
- `ANSWER_PATTERNS` - для правильных ответов

### Добавление новых эндпоинтов API

Отредактируйте `api/app.py`, добавив новые роуты:

```python
@app.route('/api/my_endpoint', methods=['GET'])
def my_endpoint():
    return jsonify({"result": "success"})
```

# 🚀 Быстрый старт - Полный цикл

## Шаг 1: Установка (один раз)

```bash
# Создаём виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt
```

## Шаг 2: Скачивание олимпиад

### Первый раз - полная загрузка

```bash
python olympiad_downloader.py --full
```

Скрипт скачает PDF со всех университетов:
- МГУ (Ломоносов)
- ВШЭ (Высшая проба)
- ВСОШ
- РАНХиГС
- СПбГУ
- МГИМО

По предметам:
- Религиоведение
- Обществознание
- Философия
- Право
- Политология
- Социология
- Экономика
- История

**Файлы сохраняются в:** `olympiads/downloads/`

### Обновление - только новые материалы

```bash
python olympiad_downloader.py --update
```

✅ Скачает только **новые** файлы
✅ **Не будет** повторно загружать существующие
✅ Отслеживает по базе: `olympiads/database.json`

**Запускайте периодически** (например, раз в месяц) для получения свежих материалов!

## Шаг 3: Импорт в базу данных

### Импорт всех скачанных PDF

```bash
python import_pdfs.py olympiads/downloads
```

### Импорт конкретного предмета

```bash
# Только философия
python import_pdfs.py olympiads/downloads --pattern "**/*филос*.pdf"

# Только обществознание
python import_pdfs.py olympiads/downloads --pattern "**/*общество*.pdf"
```

### Импорт с извлечением изображений (графиков, диаграмм)

```bash
python import_pdfs.py olympiads/downloads
# По умолчанию извлекает изображения

# Или без изображений (быстрее)
python import_pdfs.py olympiads/downloads --no-images
```

### Тестовый импорт (первые 5 файлов)

```bash
python import_pdfs.py olympiads/downloads --limit 5
```

## Шаг 4: Запуск системы

### Простой способ

```bash
./start.sh
```

Автоматически:
- ✅ Запустит API (http://localhost:5001)
- ✅ Запустит веб-интерфейс (http://localhost:8000)
- ✅ Откроет браузер

### Остановка системы

```bash
./stop.sh
```

## Использование веб-интерфейса

### Просмотр вопросов

1. Вкладка "📚 Просмотр вопросов"
2. Выберите фильтры:
   - Предмет (Философия, Обществознание и т.д.)
   - Университет (МГУ, ВШЭ и т.д.)
   - Год (2024, 2023 и т.д.)
   - Тип вопроса
   - Сложность (1-5)
3. Нажмите "Применить фильтры"
4. **Для любого вопроса можно нажать "📄 PDF"** чтобы открыть исходный файл!

### Тестирование

1. Вкладка "✏️ Тестирование"
2. Выберите:
   - Предмет
   - Количество вопросов (10, 20, 50...)
3. Нажмите "Начать тест"
4. Отвечайте на вопросы
5. Получите результат (% правильных ответов)

### Статистика

Вкладка "📊 Статистика" показывает:
- Общее количество вопросов
- Распределение по предметам
- Распределение по университетам

## 📋 Типичный рабочий процесс

### Первая настройка (один раз)

```bash
# 1. Установка
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 2. Скачивание олимпиад
python olympiad_downloader.py --full

# 3. Импорт в БД
python import_pdfs.py olympiads/downloads --limit 50

# 4. Запуск
./start.sh
```

### Регулярное обновление (раз в месяц)

```bash
# 1. Активируем окружение
source venv/bin/activate

# 2. Скачиваем новые материалы
python olympiad_downloader.py --update

# 3. Импортируем новые PDF
python import_pdfs.py olympiads/downloads

# 4. Синхронизируем БД и перезапускаем
./stop.sh
./start.sh
```

### Быстрая работа (каждый день)

```bash
# Просто запускаем систему
./start.sh

# Работаем с вопросами через браузер
# http://localhost:8000

# Закончили - останавливаем
./stop.sh
```

## ⚠️ Частые проблемы

### Порт 5001 занят

Измените порт в файлах:
- `api/app.py` (строка с `port=5001`)
- `web/app.js` (строка с `API_URL`)

### База данных не синхронизируется

```bash
cp olympiad_questions.db api/olympiad_questions.db
```

### Виртуальное окружение не активировано

```bash
source venv/bin/activate
```

### Не работает парсинг PDF

Проверьте установку PyMuPDF:

```bash
pip install PyMuPDF --upgrade
```

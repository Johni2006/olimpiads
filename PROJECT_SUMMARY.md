## 🚀 Как использовать

### Полный цикл

1. **Скачать олимпиады:**
   ```bash
   python olympiad_downloader.py --full
   ```

2. **Импортировать в БД:**
   ```bash
   python import_pdfs.py olympiads/downloads
   ```

3. **Запустить систему:**
   ```bash
   ./start.sh
   ```

4. **Открыть браузер:**
   http://localhost:8000

5. **Обновлять периодически:**
   ```bash
   python olympiad_downloader.py --update
   python import_pdfs.py olympiads/downloads
   ./start.sh
   ```

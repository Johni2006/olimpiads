# 🔒 Защита данных и резервное копирование

## Автоматические бэкапы

### Создать бэкап вручную
```bash
./backup_db.sh
```

Бэкапы сохраняются в `database/backups/` с timestamp в имени файла.

**Политика хранения:**
- Последние 30 бэкапов хранятся несжатыми
- Бэкапы старше 1 дня автоматически сжимаются (gzip)
- Храним до 100 сжатых бэкапов

### Синхронизация БД
```bash
./sync_db.sh
```

Автоматически определяет, какая БД новее (корневая или в `api/`) и синхронизирует.

## Рекомендуемый workflow

### Перед началом работы:
```bash
./backup_db.sh    # Создать бэкап
./sync_db.sh      # Синхронизировать
```

### После редактирования вопросов:
```bash
./backup_db.sh    # Сохранить изменения
./sync_db.sh      # Синхронизировать с api/
```

### Перед обновлением/импортом новых PDF:
```bash
./backup_db.sh    # Обязательный бэкап перед изменениями
```

## Восстановление из бэкапа

### Посмотреть список бэкапов:
```bash
ls -lh database/backups/
```

### Восстановить из бэкапа:
```bash
# Сначала создайте бэкап текущего состояния
./backup_db.sh

# Восстановите нужную версию
cp database/backups/olympiad_questions_YYYYMMDD_HHMMSS.db olympiad_questions.db

# Синхронизируйте
./sync_db.sh
```

### Восстановить из сжатого бэкапа:
```bash
gunzip -c database/backups/olympiad_questions_YYYYMMDD_HHMMSS.db.gz > olympiad_questions.db
./sync_db.sh
```

## Подготовка к деплою

Перед деплоем на продакшн:

1. Создайте финальный бэкап:
   ```bash
   ./backup_db.sh
   cp olympiad_questions.db olympiad_questions_PRODUCTION_READY.db
   ```

2. Проверьте целостность:
   ```bash
   sqlite3 olympiad_questions.db "PRAGMA integrity_check;"
   ```

3. Экспортируйте важные данные отдельно:
   ```bash
   sqlite3 olympiad_questions.db ".dump pdf_files" > pdf_metadata_backup.sql
   ```

## Важно!

- ✅ **Бэкапы НЕ коммитятся в git** (добавлены в .gitignore)
- ✅ **БД автоматически синхронизируется** между корнем и api/
- ✅ **Старые бэкапы сжимаются** для экономии места
- ⚠️ **Делайте бэкап перед крупными изменениями**
- ⚠️ **Проверяйте успешность восстановления** из бэкапа периодически

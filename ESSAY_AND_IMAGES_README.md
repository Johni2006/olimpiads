# Поддержка типа вопроса "Эссе" и изображений в вариантах ответов

## 1. ТИП ВОПРОСА "ЭССЕ" (Essay)

### Описание
Добавлен новый тип вопроса `essay` для олимпиадных заданий, требующих развёрнутого письменного ответа.

### Особенности

#### Структура вопроса-эссе:
- **Тип**: `essay`
- **Текст задания**: полное описание темы и требований
- **Рекомендации по оцениванию**: поле `essay_guidelines` с критериями проверки
- **Баллы**: количество баллов за эссе (обычно выше, чем за тестовые вопросы)
- **Сложность**: 1-5 (как у других типов вопросов)

#### Поле `essay_guidelines`:
Содержит детальные критерии оценивания:
- Критерии по содержанию
- Критерии по структуре
- Критерии по языку
- Критерии по оригинальности
- Примечания и штрафы
- Примеры оценивания

### Пример создания вопроса-эссе:

```python
import sqlite3

conn = sqlite3.connect("olympiad_questions.db")
cursor = conn.cursor()

cursor.execute("""
    INSERT INTO questions (
        text, type, difficulty, points, essay_guidelines,
        source_pdf, page_number
    ) VALUES (?, ?, ?, ?, ?, ?, ?)
""", (
    "Напишите эссе на тему...",  # Текст задания
    "essay",                      # Тип вопроса
    4,                            # Сложность
    10.0,                         # Баллы
    "КРИТЕРИИ ОЦЕНИВАНИЯ...",     # Рекомендации
    "olympiads/manual/essay.pdf", # Источник
    1                             # Страница
))

conn.commit()
```

### Отображение на фронтенде:

**Для студента:**
- Вопрос с полным текстом задания
- **Textarea** для ввода ответа (удобное большое поле)
- Счётчик слов (если требуется минимальный объём)
- Таймер (если ограничено время)

**Для проверяющего:**
- Текст задания
- Ответ студента
- Рекомендации по оцениванию (`essay_guidelines`)
- Поле для выставления балла
- Поле для комментариев

## 2. ИЗОБРАЖЕНИЯ В ВАРИАНТАХ ОТВЕТОВ

### Описание
Система уже поддерживает добавление изображений как к вопросам, так и к вариантам ответов через таблицу `images`.

### Структура таблицы `images`:

```sql
CREATE TABLE images (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    question_id INTEGER,           -- ID вопроса
    option_id INTEGER,             -- ID варианта ответа (NULL если изображение к вопросу)
    file_path VARCHAR(500),        -- Путь к файлу
    image_type VARCHAR(50),        -- Тип: 'graph', 'diagram', 'photo', 'scheme', 'other'
    position INTEGER DEFAULT 0,    -- Позиция в вопросе/варианте
    width INTEGER,                 -- Ширина
    height INTEGER,                -- Высота
    description TEXT,              -- Описание
    created_at TIMESTAMP
);
```

### Типы изображений:

1. **Изображение в вопросе**: `option_id = NULL`
   - Показывается перед текстом вопроса или после
   - Может быть несколько (управляется через `position`)

2. **Изображение в варианте ответа**: `option_id = <ID варианта>`
   - Показывается рядом с текстом варианта
   - Варианты могут быть только изображениями (без текста)

### Пример: Добавление изображения к вопросу

```python
cursor.execute("""
    INSERT INTO images (
        question_id, file_path, image_type, position, description
    ) VALUES (?, ?, ?, ?, ?)
""", (
    123,                                    # ID вопроса
    "question_images/diagram_123.png",     # Путь к файлу
    "diagram",                             # Тип изображения
    0,                                     # Позиция
    "Схема философских категорий"         # Описание
))
```

### Пример: Добавление изображения к варианту ответа

```python
# Создаём вариант ответа
cursor.execute("""
    INSERT INTO options (question_id, text, is_correct, position)
    VALUES (?, ?, ?, ?)
""", (123, "График A", True, 0))

option_id = cursor.lastrowid

# Добавляем изображение к этому варианту
cursor.execute("""
    INSERT INTO images (
        question_id, option_id, file_path, image_type, position
    ) VALUES (?, ?, ?, ?, ?)
""", (
    123,                                # ID вопроса
    option_id,                          # ID варианта
    "question_images/graph_a.png",      # Путь к файлу
    "graph",                            # Тип
    0                                   # Позиция
))
```

## 6. РЕКОМЕНДАЦИИ ПО ИСПОЛЬЗОВАНИЮ

### Для типа "essay":
1. **Чёткое задание**: Указывайте структуру, объём, аспекты для раскрытия
2. **Подробные критерии**: В `essay_guidelines` детально опишите шкалу оценивания
3. **Примеры**: Можно добавить примеры хороших и плохих ответов
4. **Время**: Учитывайте время на написание (обычно 30-60 минут)

### Для изображений в вариантах:
1. **Оптимизация**: Используйте оптимизированные изображения (PNG/JPG, до 500KB)
2. **Размер**: Указывайте width/height для корректного отображения
3. **Альтернатива**: Всегда добавляйте description для доступности
4. **Типы**: Правильно указывайте image_type для удобной фильтрации

### Вопрос с изображениями в вариантах:

```sql
-- Вопрос: Какой график изображает линейную функцию?
INSERT INTO questions (text, type) VALUES ('Выберите график линейной функции', 'choice');
SET @question_id = LAST_INSERT_ID();

-- Вариант A (с изображением)
INSERT INTO options (question_id, text, is_correct) VALUES (@question_id, 'График A', 0);
SET @option_a = LAST_INSERT_ID();
INSERT INTO images (question_id, option_id, file_path, image_type)
VALUES (@question_id, @option_a, 'images/graph_a.png', 'graph');

-- Вариант B (с изображением) - правильный
INSERT INTO options (question_id, text, is_correct) VALUES (@question_id, 'График B', 1);
SET @option_b = LAST_INSERT_ID();
INSERT INTO images (question_id, option_id, file_path, image_type)
VALUES (@question_id, @option_b, 'images/graph_b.png', 'graph');
```
